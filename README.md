# mbkh_feat Mason Brick

Add a feature module to an existing **mbkh_app** project.

_Generated by [mason][1] 🧱_

## Usage

From your Flutter app root (after `mbkh_app` scaffold exists):

```bash
mason get
mason make mbkh_feat
```

## Variables

| Var | Default | Description |
|-----|---------|-------------|
| `project_name` | `mbkh_app` | Target package name (must match `pubspec.yaml` `name`) |
| `feature_name` | `sample_feature` | Feature folder name (snake_case) |
| `entity_name` | `sample_item` | Primary entity (snake_case → class `SampleItem`) |
| `usecase_action` | `get` | Initial use case verb → `GetSampleItemUsecase` |

## Generated structure

```
lib/features/<feature_name>/
  <feature_name>_di.dart          # registerFeatureStack + use case
  <feature_name>_controller.dart
  <feature_name>_state.dart
  <feature_name>_view.dart
  presentation/<feature_name>_view_phone.dart
  domain/...
  usecases/<action>_<entity>_usecase.dart
```

Follow `WIRING_REQUIRED.md` in the generated output for routes and `generated_features_di.dart`.

## Local path (with mbkh_app example)

```bash
cd mason-mbkh-app/example
mason get
mason make mbkh_feat -c mason_feat_vars.json --on-conflict overwrite
```
